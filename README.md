# AgroKontrol

CRM для учёта клиентов, оплаты и посещений теплиц (по ТЗ v1.0).
Next.js (статический экспорт) + Supabase (Postgres, авторизация, права доступа) + GitHub Pages.

## Что внутри

- **Вход по телефону и паролю**, закрытая регистрация. Роли: администратор (всё) и агроном (просмотр клиентов и оплат, календарь, визиты, заметки — без изменения сумм). Права проверяются в базе (Row Level Security), а не только в интерфейсе.
- **Клиенты и теплицы**: несколько теплиц с площадью, адресом и тарифом; архив; поиск и фильтры по району, посёлку, оплате и графику.
- **Тарифы**: руб./м², скидка или ручная цена. Период 4 недели = 4 визита; неделя = период ÷ 4.
- **Платежи**: вручную, наличные / перевод, кто принял, за какие недели; 1 или 4 недели, частичная оплата, предоплата, аванс. Долг прошлого сезона — отдельное ручное поле. Все изменения пишутся в журнал (триггеры в базе).
- **Календарь**: день / неделя / месяц, перетаскивание, лимит визитов, длительность, интервалы и дорога, автоплан с группировкой по району и посёлку, статусы визитов, заметки. Только оплаченные недели (или исключение «оплата при визите») попадают в планирование. Экспорт `.ics` (TickTick, Google, Apple).
- **Главная**: показатели, ближайшие визиты, ожидающие оплаты, загрузка дней, сводка по районам.
- **Отчёты Excel** за неделю / месяц / весь период / даты.
- **Резервные копии**: ежедневно (pg_cron), вручную, скачивание JSON, восстановление из копии или файла.
- **PWA и офлайн**: ярлык на экран, работа без сети, очередь изменений с синхронизацией без дублей (UUID с клиента) и предупреждением о конфликтах.

## Настройка

1. Создать проект на [supabase.com](https://supabase.com).
2. **SQL Editor → New query** → вставить `supabase/schema.sql` → **Run**.
3. **Authentication → Sign In / Providers**: выключить «Allow new users to sign up» (регистрация закрыта; пользователей создаёт администратор в приложении).
4. **Authentication → URL Configuration**: Site URL = адрес сайта на GitHub Pages; добавить его же в Redirect URLs (нужно для восстановления пароля по email).
5. **Project Settings → API**: скопировать Project URL и `anon` key.
6. В репозитории GitHub: **Settings → Secrets and variables → Actions → Variables**: `SUPABASE_URL`, `SUPABASE_ANON_KEY`. **Settings → Pages → Source: GitHub Actions**.
7. Открыть сайт — при первом входе будет форма создания администратора. Затем в «Настройках» администратор добавляет агронома.

## Локально

```bash
cp .env.example .env.local   # заполнить URL и ключ
npm install
npm run dev
npm test                     # проверки приёмки по ТЗ
```

## Восстановление доступа

- Агроном забыл пароль → администратор задаёт новый в «Настройки → Пользователи».
- Администратор забыл пароль → «Забыли пароль?» на странице входа (письмо на email, указанный при создании). Встроенная почта Supabase отправляет письма только адресам участников проекта Supabase; для любых адресов подключите свой SMTP (Authentication → Emails). Крайний вариант — сменить пароль в Supabase → Authentication → Users.
